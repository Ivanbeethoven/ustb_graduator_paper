\chapter{结论与展望}\label{chap:conclusion}

\section{总结}
K8s 已成为重要的容器集群编排系统，并在生产环境中广泛应用。K8s 集群中的第三方开源应用存在以 CVE 形式披露的高危权限提升漏洞，攻击者可借此突破原有权限边界，甚至控制整个集群，而相关漏洞从披露到生产环境完成补丁部署之间存在攻击窗口期。现有 K8s 安全技术针对权限提升高危漏洞的防控方面存在缺陷：一方面关注静态配置风险检测问题，缺乏针对 CVE 的有效性；另一方面动态安全监控和防护工具依赖领域特定语言，缺乏普适性。

为探索基于大模型的云原生权限提升漏洞防控技术，本文提出一种智能化安全策略生成方法KPEDefense。该方法基于安全知识库构建和多智能体工作流设计，自动生成面向权限提升相关 CVE 监控与防护的安全策略。同时开发了支持工具，并在 55 个真实漏洞样本上进行实验研究验证其可行性。主要成果如下。

(1)\textbf{提出一种智能化漏洞防控安全策略生成方法KPEDefense。}该方法首先构建面向权限提升漏洞分类框架和相关开源项目安全知识库，基于大模型的多智能体工作流进行安全策略代码生成，并利用安全上下文补充漏洞语义，通过思维链推理和反馈优化提升安全策略代码质量。为筛选最优安全策略并评估智能体方法论，提出基于多源模型排序的三维质量量化评估方法。

(2)\textbf{开发KPEDefense 支持工具。}该工具集成了 CVE 知识库管理、策略生成工作流、评审反馈交互、专家排序与策略部署等功能模块，能够为安全工程师与专家评审员提供从漏洞分析到策略部署的可操作工具支持。

(3)\textbf{实验评估。}研究在55个真实云原生权限提升漏洞上开展实验。案例分析中针对多种成因类型下的 7 个典型 CVE，在隔离环境中完成漏洞复现与策略部署，从三个评价维度验证了策略在真实攻击场景下的实际效果，说明了本方法相较现有静态风险扫描方法能针对具体漏洞给出更有效的防控手段；消融实验结果表明多智能体工作流中安全上下文构建(RAG)、思维链推理(CoT)与反馈优化(Feedback)等步骤均对策略质量有正向贡献。此外，基于多源模型排序的多维量化评估方法能够有效评估安全策略质量，缓解安全策略质量评估中的测试预言问题。

\section{展望}

作为服务计算的关键基础设施，K8s 的安全问题需要更多的学术界关注。云原生漏洞安全治理可以从如下三个角度进行进一步探索。

(1)\textbf{高危漏洞披露事件的自动化监控与知识库实时更新}。当前知识库采用离线批量构建方式，无法及时响应新披露漏洞。未来可对 GitHub Security Advisory、NVD 等公开数据源建立持续监控与订阅机制，实现增量知识库更新与策略重评估的自动化触发，缩短从漏洞披露到策略交付的响应时间。

(2)\textbf{漏洞利用的自动化复现与验证}。当前策略验证主要依赖人工模拟或静态推理，缺乏真实利用环境下的自动化验证能力。未来可基于漏洞披露信息自动搭建包含漏洞的 K8s 测试集群，结合 PoC 代码执行攻击重放，量化评估策略的阻断成功率与误报率，为策略质量评价提供更客观的证据支撑。

(3)\textbf{研究范围向其他漏洞类型扩展}。当前工作聚焦于权限提升漏洞，未来可将方法体系扩展至拒绝服务漏洞、供应链与镜像安全漏洞等云原生环境中的其他高危类型，通过扩展分类框架与优化评价维度，构建更全面的智能化安全防控能力。
