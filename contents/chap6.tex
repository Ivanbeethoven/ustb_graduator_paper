
\chapter{案例分析}\label{chap:case}
本章选取 7 个典型 CVE 案例，考察 KPEDefense 在真实云原生权限提升漏洞场景中的表现。每个案例包括\textbf{漏洞复现}、\textbf{策略生成}与\textbf{三维质量验证}三个阶段：在可控环境中重现攻击路径；基于 KPEDefense 生成监控策略与防护策略候选；从有效性 $E$、无干扰性 $I$ 与可部署性 $D$ 三个维度评估策略的阻断效果与工程可行性。


\section{案例分析实验设计}

\subsection{CVE 案例选择标准}

为保证案例具有代表性且可复现，本文按以下标准筛选 CVE：

\noindent\hangindent=2em\hangafter=1 \textbf{风险等级与影响范围}：CVSS 评分 $\geq 5.0$，在 Kubernetes 生态中影响较广，如核心组件或高使用率第三方应用漏洞。

\noindent\hangindent=2em\hangafter=1 \textbf{成因类型覆盖}：所选案例覆盖两级成因分类框架的主要类别，包括配置缺陷、安全逻辑缺陷、敏感信息泄露与代码注入，以检验方法的适用范围。

\noindent\hangindent=2em\hangafter=1 \textbf{可复现性}：具备公开 PoC 或完整技术细节，可在隔离环境中安全复现；受影响版本与修复版本明确，便于对比验证。

\noindent\hangindent=2em\hangafter=1 \textbf{防控价值}：具有明确的临时防控需求，如补丁尚未发布、业务无法立即升级或需要多层防御。

\noindent\hangindent=2em\hangafter=1 \textbf{漏洞复现流程}。对每个 CVE，按以下步骤进行复现：
\begin{enumerate}
    \item \textbf{基线环境准备}：部署受影响版本的目标组件，创建模拟业务负载与低权限身份（如 ServiceAccount）；
    \item \textbf{攻击执行}：根据公开 PoC 或技术分析模拟权限提升攻击，记录攻击步骤与异常行为；
    \item \textbf{影响确认}：验证是否成功实现权限提升（如获取集群管理员权限、访问受限资源等）。
\end{enumerate}

\noindent\hangindent=2em\hangafter=1 \textbf{策略生成与验证}。复现成功后，使用 KPEDefense 生成安全策略并进行三维评价：
\begin{enumerate}
    \item \textbf{安全上下文构建}：将 CVE 公告、组件文档、攻击日志与社区讨论输入向量知识库，检索漏洞相关证据；
    \item \textbf{策略生成}：基于安全上下文与漏洞分析结果，通过思维链推理与评审反馈优化生成候选策略；
    \item \textbf{策略部署与复测}：在测试集群部署生成策略（如 NetworkPolicy、RBAC 规则、Gatekeeper 策略等），重新执行攻击验证阻断效果；
    \item \textbf{三维质量评价}：从有效性 $E$（阻断攻击路径）、无干扰性 $I$（对业务的影响）、可部署性 $D$（配置完整性与可执行性）三个维度综合评估。
\end{enumerate}

\section{小结}
7 个覆盖不同成因类型的典型 CVE 均在隔离集群中完成了漏洞复现与策略部署验证。如表~\ref{tab:case-summary-eid}所示，生成策略在有效性维度上均能阻断或显著缓解攻击路径；在无干扰性维度上，多数策略对业务影响可控，但仍需在预生产环境验证；在可部署性维度上，策略主要依赖 Kubernetes 原生能力与成熟准入控制组件，具备模板化推广的条件。
