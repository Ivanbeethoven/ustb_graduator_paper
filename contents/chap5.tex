
\chapter{实验评估}\label{chap:experiment}\label{chap:case}

本章将近五年的云原生权限提升漏洞作为实验对象，评估 KPEDefense 的合理性和有效性，及其与现有静态扫描方法的优势。

\section{研究问题}

本章围绕以下问题展开实验：

\begin{enumerate}
\item[\textbf{(1)}] \textbf{KPEDefense方法生成安全策略的有效性如何？}
通过与常见 Kubernetes 安全风险静态扫描方法的对比，验证 KPEDefense 在权限提升漏洞防控的优势；并通过案例分析验证生成策略的实际防控效果。通过消融实验验证工作流不同步骤对有效性贡献。
\item[\textbf{(2)}] \textbf{KPEDefense在不同大语言模型下能力差异如何？}
需要评估不同模型在三维质量指标和输出稳定性上的表现差异。
\item[\textbf{(3)}] \textbf{KPEDefense中的安全策略静态评估方法可信度如何？}
需要从评审模型间的一致性以及与人工评审的对照结果两个角度进行验证。
\item[\textbf{(4)}] \textbf{KPEDefense 的时间与经济效率如何？}需要量化不同配置下的词元消耗、时间开销和经济成本，为实际部署中的选型提供依据。
\end{enumerate}

\section{实验设计}
\subsection{度量指标}

策略质量评估指标共识排序 $\hat{S}_\delta(\pi)$（式\eqref{eq:consensus-score}）计算的三维质量向量 $q(\pi)=\bigl(E(\pi),I(\pi),D(\pi)\bigr)$（定义~\ref{def:quality-vector}）。此外，为衡量评审模型之间的排序一致性，引入 Kendall's $W$ 协调系数\cite{kendall1939problem}（定义\ref{def:kendalls-w}）与 Spearman 等级相关系数\cite{spearman1961proof}（定义\ref{def:spearman-rho}）作为辅助度量；资源消耗则记录每次调用的输入与输出词元数及运行时间，按模型和方法配置分别聚合统计。

\begin{flatdefinition}{Kendall's $W$ 协调系数}
\label{def:kendalls-w}
设 $|\mathcal{H}|$ 个评审主体对 $n_v=|\Pi_v|$ 个候选策略在同一维度 $\delta$ 上独立给出严格全序排名，令 $r_{\delta}^{(h)}(\pi)$ 为评审主体 $h$ 对策略 $\pi$ 在维度 $\delta$ 上的秩，$R_i=\sum_{h\in\mathcal{H}}r_{\delta}^{(h)}(\pi_i)$ 为候选 $\pi_i$ 的秩和，$\bar{R}=\frac{1}{n_v}\sum_{i=1}^{n_v}R_i$ 为秩和均值，则 Kendall's $W$ 定义为
\begin{equation}\label{eq:kendalls-w}
W = \frac{12\,\sum_{i=1}^{n_v}\bigl(R_i - \bar{R}\bigr)^{2}}{|\mathcal{H}|^{2}\bigl(n_v^{3}-n_v\bigr)}
\end{equation}
$W\in[0,1]$，$W=1$ 表示所有评审主体排序完全一致，$W=0$ 表示排序彼此随机无关。
\end{flatdefinition}

\begin{flatdefinition}{Spearman 等级相关系数}
\label{def:spearman-rho}
设评审主体 $h_1$ 与 $h_2$ 对同一候选集 $\Pi_v$ 在维度 $\delta$ 上给出秩向量，对任意候选 $\pi_i$ 令 $d_i=r_{\delta}^{(h_1)}(\pi_i)-r_{\delta}^{(h_2)}(\pi_i)$ 为两者秩之差，则 Spearman 等级相关系数定义为
\begin{equation}\label{eq:spearman-rho}
\rho_{h_1,h_2}^{\delta} = 1 - \frac{6\displaystyle\sum_{i=1}^{n_v}d_i^{2}}{n_v\bigl(n_v^{2}-1\bigr)}
\end{equation}
$\rho\in[-1,1]$，$\rho=1$ 表示两位评审主体排序完全吻合，$\rho=-1$ 表示完全相反。实验中对所有评审主体对 $(h_1,h_2)\in\binom{\mathcal{H}}{2}$ 计算该系数，并汇报其分布的均值、中位数与极值。
\end{flatdefinition}

在评审阶段，将上述五个模型同时作为评审模型，对每个漏洞实例对应的候选策略在三个评价维度上分别进行独立排序。为降低评审偏差，评审前对候选策略进行随机化与匿名化处理，打乱展示顺序并隐去来源信息，以减少顺序效应和模型偏好对结果的影响。随后，对各评审模型给出的排序结果进行等权聚合，得到该漏洞实例上的共识排序 $\hat{S}_\delta(\pi)$（式\eqref{eq:consensus-score}），作为自动评审的最终结果。

针对所有CVE生成的候选安全策略集合进行人工独立评审，以检验自动评审结果与人工判断的一致性。人工评审与自动评审采用相同的评价维度、排序规则和候选展示方式，从而保证两者具有可比性。通过自动评审与人工对照相结合的方式，可以进一步验证评审结果的可靠性，并为分析自动评审方法的有效性提供依据。



\section{结果分析与讨论}

本节依次从静态扫描方法对比，从、生成模型能力、评审可信度和资源消耗四个方面展开分析。

\subsection{安全策略生成有效性}

现有静态扫描方法对权限提升 CVE 防控的参考价值有限。研究选取 \texttt{Kubescape}、\texttt{KubeSec}、\texttt{kube-linter} 和 \texttt{SLI-Kube} 作为对照方法，在相关 Kubernetes 部署清单上进行扫描，并将报告条目按统一风险类型归并统计，结果见表~\ref{tab:risk-summary-four-tools}。四种静态扫描方法的报告主要集中在配置基线与通用加固项，如资源配置缺失、身份与密钥暴露、网络隔离和非 Root 运行。这类结果对日常治理和合规检查仍有价值，但与收集的 55 个权限提升漏洞逐一对应时，能够直接指向漏洞触发前提的情况并不多。只有 CVE-2020-4062 与 CVE-2024-31989 在报告中出现了较明确的关联线索，而且都落在网络隔离项上，分别由 \texttt{Kubescape} 与 \texttt{SLI-Kube} 命中。其余样本的关键攻击路径通常依赖具体组件行为、权限边界或运行时条件，超出了静态规则直接覆盖的范围。就补丁窗口期的漏洞防控而言，静态扫描更适合作为保障方法，而 KPEDefense 更适合提供面向具体漏洞场景的处置建议。

安全上下文（RAG）的贡献度相对较小。移除后有效性降至 0.476，降幅约 18\%，无干扰性和可部署性也分别下降约 14\% 与 20\%。这与当前大语言模型的训练语料已大量涵盖开源仓库及相关 CVE 记录有关，使得去除检索模块后模型仍能在一定程度上获取漏洞相关知识。

为进一步回答 RQ1，研究选取 7 个典型 CVE，在隔离 Kubernetes 集群中开展漏洞复现、策略生成与部署验证，以考察 KPEDefense 在真实场景中的防控效果。对每个权限提升CVE，均依据如下步骤进行：
\begin{enumerate}
    \item \textbf{漏洞复现}：根据CVE描述部署受影响版本的目标组件，创建模拟业务负载与低权限身份；依据公开 PoC 或技术分析模拟权限提升攻击，记录攻击步骤与异常行为，并验证是否成功实现权限提升。
    \item \textbf{安全策略生成}：基于 KPEDefense 系统，使用至少三个大模型生成候选安全策略，并从有效性 $E$、无干扰性 $I$、可部署性 $D$ 三个维度进行静态评估，筛选出最优策略集合。
    \item \textbf{策略验证}：部署生成的安全策略，并重放漏洞复现过程，验证策略能否有效监控和防护漏洞，再结合三维质量评价体系分析结果。
\end{enumerate}

\subsection{不同生成模型能力评估}

五个生成模型在三个维度上并无统一的优劣排序，不同模型的优势维度存在明显分化。表~\ref{tab:generator-scores}展示了各模型在有效性 $E$、无干扰性 $I$ 与可部署性 $D$ 三个维度上的得分分布。GPT-5 在有效性维度上明显领先，得分达到 $E=0.814$，但无干扰性和可部署性分别只有 0.175 和 0.215，说明它更容易给出约束较强、处置力度较大的方案。DeepSeek 则呈现出相反倾向，其无干扰性和可部署性分别达到 $I=0.497$ 和 $D=0.605$，均为五个模型中最高，但在有效性上并不占优，因此更倾向于生成改动范围较小、部署代价较低的策略。其余模型位于这两种倾向之间。

选型时需根据场景优先级权衡维度侧重。GPT-5 在有效性上优势明显且输出零失误，适合以封堵充分性为首要目标的场景；DeepSeek 在无干扰性和可部署性上领先，更适合业务连续性要求较高的环境。Qwen3-Max、GLM-4.5 和 Grok4 各维度表现较为均衡，可在不同成本约束下提供可用的折中方案。

\section{小结}
本章围绕 KPEDefense 开展实验验证，从静态扫描方法对比与案例分析、消融实验、生成模型能力、评审方法可信度和资源消耗五个方面进行了分析。实验结果验证了 KPEDefense 在策略生成与评审中的有效性，7 个典型 CVE 案例的复现与部署验证进一步表明生成策略能够有效阻断或缓解攻击路径，并展示了不同模型与配置在质量和成本上的差异。
