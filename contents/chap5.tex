
\chapter{实验研究}\label{chap:experiment}

本章对第三章和第四章提出的方法进行系统性实验验证。首先给出研究问题与实验设置，随后从消融实验、模型能力、评审可信度、静态工具对比和资源消耗五个方面展开结果分析与讨论。

\section{研究问题}

本章实验围绕以下问题展开：

\begin{enumerate}
\item[\textbf{(1)}] \textbf{三个核心模块在三维质量指标上的贡献如何？}该方法采用检索增强、思维链推理与反馈优化三个模块协同工作，各模块对策略有效性、无干扰性与可部署性的各自贡献及跨模型稳健性有待验证。
\item[\textbf{(2)}] \textbf{不同大语言模型在策略生成任务中的能力差异如何？}不同模型可能呈现出不同的策略风格倾向，需要评估其在三维质量指标和输出稳定性上的表现。
\item[\textbf{(3)}] \textbf{基于大语言模型的自动化评审方法是否具备足够的可信度？}实验结论依赖于评审结果的可靠性，需要从评审模型间的内部一致性和与人工评审的外部对照两个角度加以验证。
\item[\textbf{(4)}] \textbf{相较于现有静态分析工具，本文方法能否提供更具针对性的处置方案？}静态扫描工具是当前主流的安全检测手段，需要与之对比以验证本文方法在漏洞处置精度上的优势。
\item[\textbf{(5)}] \textbf{不同模型与方法配置在资源消耗上呈现怎样的成本效益特征？}生成式流程涉及多轮调用，不同配置下的词元消耗、时间开销和经济成本需要量化评估，以支持实际部署中的选型决策。
\end{enumerate}

\section{实验设计}

\subsection{度量指标}

本文对生成策略的质量采用三维评价体系，对应第三章定义的质量向量 $q(\pi)=\bigl(E(\pi),I(\pi),D(\pi)\bigr)$，三个维度的含义如下：

\begin{itemize}
\item \textbf{有效性 $E(\pi)$}：衡量策略对漏洞攻击路径的封堵程度，包括是否覆盖关键利用前提、是否消除或限制权限提升的可行路径。得分越高，表示策略对漏洞的处置越充分。
\item \textbf{无干扰性 $I(\pi)$}：衡量策略对现有业务功能的影响程度，包括是否引入不必要的访问限制、是否破坏正常服务间通信或资源调度。得分越高，表示策略对业务的副作用越小。
\item \textbf{可部署性 $D(\pi)$}：衡量策略在目标环境中落地的难易程度，包括配置片段是否语法正确且可直接应用、是否依赖额外的组件安装或集群变更。得分越高，表示策略越容易部署。
\end{itemize}

由于大语言模型在绝对评分任务中难以维持稳定的内部尺度\cite{wu2024scoring}，本文采用\textbf{基于排序的相对评价}作为基础信号。具体而言，评审模型对同一批候选策略在每个维度上给出从优到劣的严格排序，而非直接赋予分值。随后依据第三章的多源排名聚合模型（定义~5--6），将各评审模型的排序通过秩函数 $r_\delta^{(h)}$ 映射为归一化得分 $s_\delta^{(h)}(\pi)$，再以等权方式计算共识得分 $\hat{S}_\delta(\pi)$，据此形成各维度的共识排序。

此外，为衡量评审模型之间的排序一致性，本文引入 Kendall's $W$ 协调系数与 Spearman 等级相关系数作为辅助度量。为评估资源消耗，记录每次调用的输入与输出词元数以及运行时间，并按模型和方法配置分别聚合统计。

\subsection{实验过程}

实验按以下步骤实施。首先，在统一的提示词与输出结构规范下，分别使用五个大语言模型对 55 个漏洞实例生成候选策略集合 $\Pi_v$。为验证关键模块的贡献，设置三项消融配置：移除检索增强（\texttt{w/o rag}）、移除思维链推理（\texttt{w/o cot}）、移除基于评审反馈的反馈优化（\texttt{w/o feedback}），加上完整工作流（\texttt{all}），共四种方法配置。其余流程（提示词模板、输出格式约束、后处理规则）在各配置间保持一致。

评审阶段将上述五个模型同时作为评审模型，对每个漏洞的候选策略在三个维度上独立给出排序。评审前对候选策略进行随机化与匿名化处理，以消除顺序效应和来源偏好。各评审模型的排序结果经等权聚合后形成共识排序。

此外，随机抽取 20 个 CVE 样本由人工安全专家进行独立评审，以验证自动评审结果与人工判断的一致性。人工评审遵循与自动评审相同的评价维度和排序规范。

\section{结果分析与讨论}

本节依次从消融实验、生成模型能力、评审可信度、静态工具对比和资源消耗五个方面展开分析。

\subsection{消融实验与工作流模块贡献}

完整工作流在三个维度上均排名第一，三个模块的贡献层面各有不同。反馈优化的影响最为关键：移除后有效性从 0.581 降至 0.121（降幅 79\%），无干扰性与可部署性也出现最大幅度下降，说明多轮评审反馈为策略提供了持续纠偏的机会，使候选方案能在迭代中逐步逼近可用状态。需要指出的是，该降幅可能存在混淆因素：缺少反馈优化的策略在格式规范性与结构完整性上也更差，评审模型在排序时可能同时受到内容质量与形式质量的双重影响，因此 79\% 的降幅应理解为反馈优化对策略整体可交付质量的综合贡献，而非纯粹的内容有效性差异。检索增强主要提升策略与具体漏洞场景的贴合度：移除后有效性降至 0.476（降幅约 18\%），无干扰性和可部署性也分别下降约 14\% 和 20\%，表明外部证据有助于模型围绕真实攻击面组织策略。思维链推理的效果则呈现双面性：移除后有效性下降至 0.234，但可部署性几乎不变（$D=0.398$ 对 $D=0.403$），说明分步推理在提升分析深度的同时可能增加部署复杂度。在资源受限的情况下，反馈优化和检索增强应优先保留。上述结论在单个生成模型层面同样成立——完整工作流在绝大多数模型与维度的组合上保持最优或次优，但不同模型对模块的敏感性有所差异：GPT-5 与 GLM-4.5 在移除反馈后下降更突出，DeepSeek 与 Qwen3-Max 则对检索增强的依赖更强。

\section{小结}

本章对所提方法进行了系统实验。消融实验确认 RAG、CoT 与 Feedback 三模块均有正向贡献；模型对比表明不同大语言模型在三维指标上存在明显差异；评审可信度分析验证了多模型共识排序与人工评审的一致性；与静态扫描工具的比较表明本文方法在处置精度上更具优势；资源消耗分析给出了不同预算与时限约束下的模型选择参考。
