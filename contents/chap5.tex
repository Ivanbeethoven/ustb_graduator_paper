
\chapter{实验评估}\label{chap:experiment}

本章以近五年的云原生权限提升漏洞作为实验对象，评估 KPEDefense 的合理性和有效性，及其与现有静态扫描方法的优势。

\section{研究问题}

本章围绕以下问题展开实验：

\begin{enumerate}
\item[\textbf{(1)}] \textbf{KPEDefense方法生成安全策略的有效性如何？}

通过与常见 K8s 安全风险静态扫描方法的对比，验证 KPEDefense 在权限提升漏洞监控与防护中的优势；并通过案例分析验证生成策略的实际监控与防护效果。通过消融实验验证工作流不同步骤对有效性贡献。

\item[\textbf{(2)}] \textbf{KPEDefense在不同大语言模型下能力差异如何？}

评估不同模型在有效性、无干扰性、可部署性三个维度下质量指标和输出稳定性上的表现差异。

\item[\textbf{(3)}] \textbf{KPEDefense中的安全策略静态评估方法可信性如何？}

从评审模型间的一致性以及与人工评审的对照结果两个角度验证多源模型静态评估方法的可信性。

\item[\textbf{(4)}] \textbf{KPEDefense 的时间与经济效率如何？}

量化不同配置下的词元消耗、时间开销和经济成本，为实际部署中的选型提供依据。

\end{enumerate}

\section{实验设计}
本小节描述实验评估使用的度量指标、基线方法、实验环境设置和实验流程设置。

\subsection{度量指标}

策略质量评估指标基于共识得分 $\hat{S}_\delta(\pi)$(式\eqref{eq:consensus-score})计算三维质量向量 $q(\pi)=\bigl(E(\pi),I(\pi),D(\pi)\bigr)$(定义~\ref{def:quality-vector})。此外，为衡量评审模型之间的排序一致性，引入 Kendall's $W$ 协调系数\cite{kendall1939problem}(定义\ref{def:kendalls-w})与 Spearman 等级相关系数\cite{spearman1961proof}(定义\ref{def:spearman-rho})作为辅助度量；资源消耗则记录每次调用的输入与输出词元数及运行时间，按模型和方法配置分别聚合统计。

\begin{flatdefinition}{Kendall's $W$ 协调系数}
\label{def:kendalls-w}
设 $|\mathcal{H}|$ 个评审主体对 $n_v=|\Pi_v|$ 个候选策略在同一维度 $\delta$ 上独立给出严格全序排名，令 $r_{\delta}^{(h)}(\pi)$ 为评审主体 $h$ 对策略 $\pi$ 在维度 $\delta$ 上的秩，$R_i=\sum_{h\in\mathcal{H}}r_{\delta}^{(h)}(\pi_i)$ 为候选 $\pi_i$ 的秩和，$\bar{R}_{\mathrm{sum}}=\frac{1}{n_v}\sum_{i=1}^{n_v}R_i$ 为秩和均值，则 Kendall's $W$ 定义为
\begin{equation}\label{eq:kendalls-w}
W = \frac{12\,\sum_{i=1}^{n_v}\bigl(R_i - \bar{R}_{\mathrm{sum}}\bigr)^{2}}{|\mathcal{H}|^{2}\bigl(n_v^{3}-n_v\bigr)}
\end{equation}
$W\in[0,1]$，$W=1$ 表示所有评审主体排序完全一致，$W=0$ 表示排序彼此随机无关。
\end{flatdefinition}

\begin{flatdefinition}{Spearman 等级相关系数}
\label{def:spearman-rho}
设评审主体 $h_1$ 与 $h_2$ 对同一候选集 $\Pi_v$ 在维度 $\delta$ 上给出秩向量，对任意候选 $\pi_i$ 令 $d_i=r_{\delta}^{(h_1)}(\pi_i)-r_{\delta}^{(h_2)}(\pi_i)$ 为两者秩之差，则 Spearman 等级相关系数定义为
\begin{equation}\label{eq:spearman-rho}
\rho_{h_1,h_2}^{\delta} = 1 - \frac{6\displaystyle\sum_{i=1}^{n_v}d_i^{2}}{n_v\bigl(n_v^{2}-1\bigr)}
\end{equation}
$\rho\in[-1,1]$，$\rho=1$ 表示两位评审主体排序完全吻合，$\rho=-1$ 表示完全相反。实验中对所有评审主体对 $(h_1,h_2)\in\binom{\mathcal{H}}{2}$ 计算该系数，并汇报其分布的均值、中位数与极值。
\end{flatdefinition}

\subsection{实验流程设置}
首先针对权限提升漏洞相关的应用版本的配置文件进行风险扫描。采用四个不同静态工具(表\ref{tab:static-tools})对配置文件进行静态扫描，并生成风险合规报告，再人工评估其对策略生成的实际帮助，包括能否定位与漏洞路径相关的高风险配置，以及是否给出可直接落地的修正建议。

安全策略评估阶段，将上述五个模型(表\ref{tab:llm-models-info})同时作为评审模型，对每个漏洞实例对应的候选策略在三个评价维度上分别进行独立排序，得到该漏洞实例上的共识得分 $\hat{S}_\delta(\pi)$(式\eqref{eq:consensus-score})，并据此形成共识排序 $\bar R_{\delta}$，作为自动评审的最终结果。选择最佳策略用于案例分析。同时针对所有CVE生成的候选安全策略集合进行人工独立评审，以检验自动评审结果与人工判断的一致性。人工评审与自动评审采用相同的评价维度、排序规则和候选展示方式，从而保证两者具有可比性。

\section{结果分析与讨论}

本节依次从安全策略生成有效性、大模型能力差异、评估方法可信性、方法成本与效率四个方面展开分析。

\subsection{安全策略生成有效性}

现有静态扫描方法对权限提升 CVE 监控与防护的参考价值有限。研究选取四种静态方法作为对照的扫描结果见表~\ref{tab:risk-summary-four-tools}。与收集的 55 个权限提升漏洞逐一对应时，只有漏洞编号 CVE-2020-4062 与 CVE-2024-31989 在报告中出现了较明确的关联线索，且只有网络隔离一种分类类别，分别由 Kubescape 与 SLI-Kube 命中。就补丁窗口期的漏洞监控与防护而言，静态扫描更适合作为安全基线检查与辅助分析手段，而难以直接生成面向具体 CVE 的临时处置策略；KPEDefense 则更适合提供面向具体漏洞场景的处置建议。

消融实验表明，三个步骤均能提升策略质量，其中反馈优化的影响最为显著。完整工作流 KPEDefense与三种消融配置 KPEDefense w/o RAG、KPEDefense w/o CoT、KPEDefense w/o Feedback的三维质量得分见表~\ref{tab:ablation-scores}，评价维度为有效性 $E$、无干扰性 $I$ 与可部署性 $D$。55 个漏洞样本先由五个生成模型产出候选策略，再交由五个评审模型独立排序，最后经等权聚合得到各维度共识得分。其中反馈优化(Feedback)移除后有效性降幅达 79\%，无干扰性与可部署性也同步出现最大下降。多轮反馈迭代对各维度质量的提升作用最为全面，然而代价是更高的词元消耗与时间开销。思维链推理(CoT)的影响则呈现明显的维度分化：移除后有效性降至 0.234，但可部署性几乎不变($D=0.403$ 降至 $D=0.398$)。安全上下文(RAG)的贡献度相对较小，移除后有效性降至 0.476，降幅约 18\%，无干扰性和可部署性也分别下降约 14\% 与 20\%。一种可能解释是，当前大语言模型的训练语料可能已涵盖部分开源仓库及相关 CVE 记录，使得去除检索模块后模型仍能在一定程度上利用参数化知识感知漏洞相关信息；但该解释仍需通过控制模型训练数据可见性或使用新披露漏洞样本进一步验证。值得一提的是，部分本身进行思维链推理的模型中 CoT 部分的提升较少。

\section{小结}
本章围绕 KPEDefense 开展实验验证，从静态扫描方法对比与案例分析、消融实验、生成模型能力、评估方法可信度和资源消耗五个方面进行了分析。实验结果验证了 KPEDefense 在策略生成与评估中的有效性，7 个典型 CVE 案例的复现与部署验证进一步表明生成策略能够有效阻断或缓解攻击路径，并展示了不同模型与方法在质量和成本上的差异。
