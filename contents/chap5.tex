\chapter{实验研究}\label{chap:experiment}


\section{研究问题}

本章实验旨在验证所提方法在权限提升漏洞实时防控场景下的有效性与适用性，具体围绕以下研究问题展开：

\paragraph{RQ1:}
在权限提升漏洞的临时防控场景下,本文提出方法的不同步骤能否在有效性($E$)、无干扰性($I$)与可部署性($D$)三个维度上相对消融配置提供一致性增益?
\paragraph{RQ2:}
本文工作流的相对优势是否对不同生成模型与评审模型稳健,是否存在系统性的能力分层或偏好差异?
\paragraph{RQ3:}
在多评审模型参与的排名式评价中,不同评审模型给出的相对次序是否具有足够的一致性以支撑跨评审聚合与反馈闭环?
\paragraph{RQ4:}
对比现有静态扫描工具,本文方法能否为具体CVE的临时防控提供实质性的处置价值突破?
\paragraph{RQ5:}
本文方法在令牌消耗与经济成本上的表现如何,在给定资源预算下存在何种成本-收益折衷?

\section{实验设置}

评审阶段将上述五个模型作为评审模型，对 $\Pi_v$ 进行排名式评价。评价指标采用三维质量向量 $q(\pi)=(E(\pi),I(\pi),D(\pi))$，分别对应有效性、无干扰性与可部署性。为缓解大模型评分能力缺陷\cite{wu2024scoring}，降低不同评审模型评分尺度差异带来的影响，本文以相对排序作为效果评估质量。同时我们将所有评审模型的结果进行聚合，采用算术平均排名作为最终排序依据，以增强结果的稳健性与可解释性。

为回答有关令牌消耗与大模型调用成本的问题，本文在生成与评审阶段记录每次调用的输入与输出的令牌数，并按漏洞样本（CVE）聚合统计令牌消耗；对于包含反馈迭代的配置，累计其多轮调用的令牌消耗。

\section{RQ1：防控技术工作流整体优势}

本节验证所提方法的完整工作流 \texttt{all} 相对于三项消融配置在三维质量指标上的一致性增益，并考察不同生成模型条件下的稳健性表现。除非特别说明，统计结果均在 55 个漏洞样本上汇总，评审侧采用排名式结果作为主要口径。

\subsection{方法配置的相对排名}

图\ref{fig:method-ranking-overview}呈现四种方法配置在 $E$、$I$ 与 $D$ 三个维度上的排名分布，数值越小代表防控效果越优。统计流程如下：55 个权限提升漏洞实例分别经五个生成模型生成候选策略，继而由五个评审模型独立评审并给出排名，最终对所有评审模型的排名取算术平均作为该方法配置的综合排名。这一评审聚合机制可有效抑制单一评审模型的主观偏差，增强排名结果的统计稳健性。

\begin{figure}[!ht]
	\centering
	{\setlength{\abovecaptionskip}{2pt}%
	 \setlength{\belowcaptionskip}{0pt}%
	 \includegraphics[width=0.85\textwidth]{images/output_rank_order/method_rank_order.png}}
	\caption{方法配置在三个维度上的排名对比。}\label{fig:method-ranking-overview}
\end{figure}

实验结果显示，完整工作流 \texttt{all} 在三维度上均居首位，综合平均排名为 $1.00$。消融检索增强模块后，\texttt{w/o rag} 的平均排名下滑至 $2.33$，反映检索增强对漏洞上下文理解与策略生成质量的显著贡献；移除思维链推导的 \texttt{w/o cot} 配置平均排名为 $2.67$，验证了分阶段推理对复杂漏洞防控策略生成的必要性；而移除基于评审反馈的迭代优化机制导致 \texttt{w/o feedback} 出现最严重的性能退化，平均排名降至 $4.00$，证实反馈闭环是提升策略质量的核心环节。

进一步观察可发现，\texttt{w/o cot} 在 $E$ 与 $I$ 维度上均劣于 \texttt{w/o rag}，但在 $D$ 维度上略优，排名分别为 $2.0$ 与 $3.0$。这一现象可归因于思维链推导在明确漏洞路径后倾向于生成复杂度较高的策略，简化推导过程反而降低了部署负担。尽管存在单维度差异，综合三维表现，检索增强模块的整体贡献仍优于思维链推导模块。完整工作流在各维度上的排名均显著优于消融配置，特别是反馈迭代机制的缺失对三个维度均造成严重退化，凸显其作为工作流核心环节的关键作用。

\subsection{生成模型的相对排名}

图\ref{fig:generator-ranking-overview}呈现五个生成模型在三维度上的排名分布。统计流程与前述方法配置排名一致：每个生成模型在 55 个漏洞实例上生成的策略由五个评审模型独立排名后取算术平均，得到该生成模型在各维度上的综合排名。

\begin{figure}[!ht]
	\centering
	{\setlength{\abovecaptionskip}{2pt}%
	 \setlength{\belowcaptionskip}{0pt}%
	 \includegraphics[width=0.85\textwidth]{images/output_rank_order/profile_rank_order.png}}
	\caption{生成模型在三个维度上的排名对比。}\label{fig:generator-ranking-overview}
\end{figure}

实验数据揭示，\texttt{DeepSeek 3.1} 在综合平衡性上表现最优，平均排名为 $1.67$，在 $I$ 与 $D$ 维度上均位列首位，排名均为 $1.0$，仅在 $E$ 维度上排名第三，排名为 $3.0$。这表征 DeepSeek 在生成策略时能够有效平衡漏洞防控效果与实际部署约束，规避过度复杂或侵入性强的策略设计。\texttt{Qwen3-Max} 在三维度上均保持中上水平，平均排名为 $2.67$，其在 $E$、$I$、$D$ 上的排名分别为 $4.0$、$2.0$、$2.0$，呈现较为均衡的能力分布。

\texttt{GPT-5} 呈现显著的维度分化特征：在 $E$ 维度上排名首位，排名为 $1.0$，但在 $I$ 与 $D$ 维度上均排名垫底，均为 $5.0$。这一分化现象揭示 GPT-5 在生成策略时更注重漏洞防控的彻底性，倾向于采用严格的隔离与限制措施，但忽视了对业务系统的副作用与部署复杂度。与之形成对照，\texttt{Grok4} 在 $E$ 维度上排名最低，排名为 $5.0$，但在 $I$ 与 $D$ 维度上保持中游水平，排名均为 $3.0$，平均排名为 $3.67$，适用于对部署成本敏感、可容忍较弱防控强度的应急响应场景。

\texttt{GLM-4.5} 的维度分化模式与 GPT-5 相似但程度较轻：在 $E$ 维度上排名第二，排名为 $2.0$，但在 $I$ 与 $D$ 维度上均排名第四，均为 $4.0$，平均排名为 $3.33$。从整体视角考察，五个生成模型在三维质量指标上表征出明显的能力分化与取舍倾向。DeepSeek 的均衡优势与 GPT-5 的维度分化现象在可视化结果中尤为清晰，为后续基于维度加权的多智能体策略组合提供了实证依据。

\subsection{关键结论}

基于上述排名统计，本节针对 RQ1 给出如下结论：

\paragraph{方法工作流的一致性增益}
完整工作流 \texttt{all} 在 $E$、$I$ 与 $D$ 三维度上均取得最优排名，综合平均排名为 $1.00$，显著优于任何消融配置。实验验证了检索增强、思维链推导与反馈迭代三个模块的协同作用能够为权限提升漏洞的临时防控提供一致性增益。其中，反馈迭代机制的缺失对三维度均造成最严重的性能退化，平均排名降至 $4.00$，证实其作为工作流核心环节的关键地位。

\paragraph{生成模型的能力分化}
五个生成模型在三维质量指标上表征出明显的能力分化：\texttt{DeepSeek 3.1} 在综合平衡性上表现最优，平均排名为 $1.67$，适用于对部署约束与业务连续性敏感的生产环境；\texttt{GPT-5} 在漏洞防控有效性上排名首位，但在 $I$ 与 $D$ 维度上表现不佳，平均排名为 $3.67$，适用于对安全性要求极高且可容忍较高部署成本的场景；\texttt{Grok4} 在 $E$ 维度上表现最弱，但在部署友好性上保持中游水平，可作为快速响应的轻量级方案。实验发现为多智能体协同策略提供了实证依据：在实际部署中，可依据具体漏洞的风险等级与业务约束动态选择或组合不同生成模型。

\subsection{模型内容对其能力评估}

为评估不同生成模型在策略生成过程中的稳定性与输出质量，本文统计了各模型在生成阶段触发重试的次数。重试机制主要针对三类失败情形：结构化输出的 JSON 格式错误（通常因字段缺失、括号不匹配或编码问题）、生成内容的语法错误（包括 YAML 语法错误、逻辑矛盾或不可解析的配置片段），以及内容违规（触发模型供应商的安全策略或内容审核机制）。为便于跨模型对比，本文将计数按固定分母 504 归一化为失误率（失败发生率）。表\ref{tab:model-retry-stats} 给出五个生成模型的失误率统计（=计数/504）。

整体上，GPT-5 在三类错误上均无重试记录，表现出较高的生成鲁棒性；Grok 和 DeepSeek 的失误率较低，输出稳定性良好；Qwen3 与 GLM-4.5 的失误率相对较高，尤其在 JSON 格式错误上，GLM-4.5 的失误率为 4.56\%（=23/504），反映其在结构化输出约束下的遵循能力有待提升。语法错误维度上，GLM-4.5 同样表现出明显劣势（1.98\%=10/504），而其余模型均不超过 0.99\%（=5/504）。值得注意的是，GLM-4.5 是唯一触发内容违规的模型（1.98\%=10/504），可能与其内容审核策略对高危漏洞描述配中的安全关键词过度敏感相关。该统计为模型选型与多智能体协同策略提供了量化参考：在资源受限或对输出稳定性敏感的场景下，优先选用 GPT-5、Grok 或 DeepSeek；而对于需要多样性候选集的场景，可将 Qwen3 与 GLM-4.5 纳入候选池，但需配置更宽松的重试预算与后处理容错机制。

\section{RQ3：评价一致性与可信度}

本节聚焦于评审阶段的“排序式评价”是否具备足够的一致性，从而支撑前述跨评审聚合统计与反馈闭环（RQ1--RQ2）。直观而言，若不同评审者（评审模型）对候选项优劣的判断高度一致，则聚合后的排序结果更稳定、更可解释；反之，若一致性较弱，则需要警惕“评审者选择敏感性”，并进一步细化评价准则。

\subsection{一致性度量与符号约定}
在固定评价维度下，设共有 $n$ 个候选项（例如不同方法配置）与 $m$ 名评审者。候选项索引 $i=1,\dots,n$，评审者索引 $j=1,\dots,m$。令 $r_{ij}$ 表示评审者 $j$ 对候选项 $i$ 给出的名次（名次越小表示越优）。

\textbf{Kendall's $W$（协调系数）} 用于刻画多评审者整体一致性，取值范围 $[0,1]$，$W=1$ 表示完全一致：
\begin{equation}
W = \frac{12\,S}{m^2\,(n^3-n)}
\end{equation}
其中
\begin{equation}
S=\sum_{i=1}^{n}(R_i-\bar{R})^2,\quad R_i=\sum_{j=1}^{m} r_{ij},\quad \bar{R}=\frac{1}{n}\sum_{i=1}^{n}R_i.
\end{equation}

\textbf{两两 Spearman 等级相关系数} 用于刻画任意两名评审者排序趋势的一致性。对评审者 $j$ 与 $k$，其排名向量分别记为 $\mathbf{r}_j$ 与 $\mathbf{r}_k$，则
\begin{equation}
\rho_{jk}=\mathrm{corr}(\mathbf{r}_j,\mathbf{r}_k).
\end{equation}
当两位评审者排序趋势一致时，$\rho_{jk}$ 接近 $1$；当趋势相反时，$\rho_{jk}$ 接近 $-1$。

\subsection{一致性统计结果}
本文在 $E/I/D$ 三个维度内分别计算 Kendall's $W$ 与评审者两两 Spearman 相关系数，并汇总其分布统计。结果显示（见图\ref{fig:judge-corr-3d}--\ref{fig:judge-spearman-box}）：
\begin{itemize}
	\item \textbf{有效性}：一致性最高，$W=0.955$；Spearman 均值 $0.944$（中位数 $0.944$，最小 $0.904$，最大 $0.991$）。
	\item \textbf{无干扰性}：一致性较高，$W=0.846$；Spearman 均值 $0.808$（中位数 $0.839$，最小 $0.585$，最大 $0.932$）。
	\item \textbf{可部署性}：一致性相对较弱，$W=0.687$；Spearman 均值 $0.609$（中位数 $0.689$，最小 $0.238$，最大 $0.947$）。
\end{itemize}
总体结论为：一致性呈现“有效性 $>$ 无干扰性 $>$ 可部署性”的稳定梯度。

\subsection{讨论与启示}
\textbf{维度差异}：有效性维度的一致性最高，说明评审者对“漏洞路径覆盖/处置有效性”的判定依据更一致；而可部署性维度的一致性相对较弱，通常涉及工程可行性、环境依赖、部署成本与运维复杂度等多因素权衡，不同评审者对权重与阈值的设定更易出现系统性差异。

\textbf{对聚合与反馈闭环的影响}：较高的 $W$ 与较高的 Spearman 均值意味着跨评审聚合后的排序更稳定，可为 RQ1--RQ2 的结论提供可信支撑；对于一致性较弱的维度（如可部署性），后续可通过细化评价准则、增加案例边界说明，或采用鲁棒聚合策略降低对单一评审者偏好的敏感性。
