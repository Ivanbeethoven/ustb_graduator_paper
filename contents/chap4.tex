\chapter{面向云原生权限提升智能化漏洞防控系统工具}\label{chap:system}

本章详细介绍 KPEAgent 系统的设计与实现，包括用户角色、总体架构、数据流转、交互时序及底层数据模型。系统旨在辅助安全工程师高效完成漏洞分析、策略生成与验证工作，并通过可视化的交互界面提供全程可控的决策支持。

\section{角色与用例分析}

系统的核心用户角色包括安全工程师与专家评审员。安全工程师负责会话创建与策略生成，利用系统的 RAG 与 COT 能力辅助分析；评审员则对生成结果进行排序与决策，确保缓解策略的安全性和有效性。

\section{系统总体架构}

为了实现高效的漏洞防控，系统采用经典的前后端分离架构，底层依赖智能体引擎进行核心推理与生成任务。图 \ref{fig:system_architecture} 展示了系统的四层架构设计：
\begin{itemize}
    \item \textbf{前端展示层}：基于 Vue3 构建，提供多视图交互 UI 和 ECharts 仪表盘。
    \item \textbf{后端服务层}：基于 Flask 开发，负责 API 路由分发与管线调度。
    \item \textbf{智能体能力层}：集成检索增强生成 (RAG)、思维链 (CoT) 与策略生成引擎。
    \item \textbf{数据持久层}：采用轻量级文件存储，管理 CVE 知识库与生成的策略产物。
\end{itemize}

\section{端到端数据流与审计}

\section{数据实体关系}

系统底层通过轻量级的文件存储管理核心数据实体。主要实体包括：
\begin{itemize}
    \item \textbf{CVE}：存储漏洞的基础描述信息。
    \item \textbf{Strategy}：存储特定会话中生成的策略详情与推理链。
    \item \textbf{Ranking}：存储专家或用户对多个候选策略的排序记录。
\end{itemize}
