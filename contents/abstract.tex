\begin{ChineseAbstract}
    
Kubernetes 是由云原生计算基金会托管的容器集群编排系统，广泛用于微服务系统的大规模容器化部署与运维。Kubernetes第三方云原生应用内可能存在导致权限提升的高危漏洞，在该类漏洞在披露至补丁落地的窗口期内，权限提升攻击风险可威胁集群内所有节点安全。现有研究侧重对配置文件的静态风险分析，难以围绕具体漏洞快速生成可用于临时防控的安全策略；现有安全工具则依赖专家经验进行策略制定，无法针对特定漏洞进行有效防控。

本文基于大语言模型漏洞分析与代码生成能力，提出一种针对权限提升漏洞的智能化安全策略生成方法。该方法通过对运行时监控、策略准入引擎、网络策略等多种安全工具的领域特定语言自动化生成与管理，对云原生应用权限提升漏洞中攻击链条节点实施动态防护与监控。主要工作如下。

\textbf{（1）提出一种智能化漏洞防控安全策略生成方法（KPEDefense）}：首先，根据历史权限提升漏洞成因系统归纳并提出了一种权限提升漏洞成因分类框架，并基于漏洞来源的开源代码仓库中的多源信息构建安全知识库。然后，在安全知识库检索信息基础上，构建由安全上下文构建、思维链推理、反馈优化等步骤组成的多智能体工作流，生成用于防护和监控特定权限提升漏洞攻击的安全策略代码。最后，设计了针对安全策略的多源模型质量量化评估方法，覆盖有效性、非干扰性与可部署性三个不同维度。

\textbf{（2）开发支持工具}：设计并开发 KPEDefense 方法支持工具，集成知识库管理、策略生成工作流、专家评审排序与策略部署验证等功能模块，实现面向云原生权限提升漏洞的智能化自动防控流程。

\textbf{（3）实验评估}：以近5年权限提升漏洞样本作为实验对象，对DPEDefense方法生成安全策略的质量和效率进行评估，并进行案例分析。实验结果表明，相较现有的规则化风险扫描方法，DPEDefense能够针对真实云原生权限提升漏洞提出更实际的防控方案，方法不同部分对安全策略有效性均有正向贡献，且时间与经济成本开销较低。

KPEDefense通过生成智能化漏洞防控安全策略，能够有效缓解Kubernetes第三方开源应用带来的权限提升等高危风险，从而保障Kubernetes集群的安全性。

\ChineseKeywords{云原生安全；权限提升漏洞；策略代码生成；补丁窗口期防控；多智能体协同}
\end{ChineseAbstract}

%% 英文摘要页
\begin{EnglishAbstract}
Kubernetes is a container cluster orchestration system hosted by the Cloud Native Computing Foundation, widely used for large-scale containerized deployment and operation of microservice systems. Third-party cloud-native applications in the Kubernetes ecosystem may contain high-risk vulnerabilities capable of enabling privilege escalation; during the window period between vulnerability disclosure and patch deployment, the risk of privilege escalation attacks can threaten the security of all nodes in a Kubernetes cluster. Existing research focuses primarily on static risk analysis of configuration files and is poorly suited to rapidly generating actionable interim security strategies for specific vulnerabilities; existing security tools rely on expert experience for policy formulation and are unable to mount targeted defenses against particular vulnerabilities.

This thesis leverages the vulnerability analysis and code generation capabilities of large language models to propose an intelligent security strategy generation method for privilege escalation vulnerabilities. By automatically generating and managing domain-specific language configurations for multiple security tools—including runtime monitors, policy admission engines, and network policies—the method implements dynamic protection and monitoring of attack chain nodes associated with privilege escalation vulnerabilities in cloud-native applications. The main contributions are as follows.

\textbf{(1) KPEDefense, an intelligent security strategy generation method for privilege escalation vulnerability prevention and control:} First, a root-cause classification framework for privilege escalation vulnerabilities is systematically proposed based on root causes observed in historical vulnerabilities, and a security knowledge base is constructed from multi-source information in the open-source repositories where the vulnerabilities originate. Then, based on retrieval from the security knowledge base, a multi-agent workflow comprising security context construction, chain-of-thought reasoning, and feedback optimization is built to generate security strategy code for protecting against and monitoring specific privilege escalation vulnerabilities. Finally, a quantitative quality evaluation method is designed for the generated strategies, covering three dimensions: effectiveness, non-interference, and deployability.

\textbf{(2) Supporting tool:} A KPEDefense support tool is designed and developed, integrating modules for knowledge-base management, strategy-generation workflow, expert review and ranking, and strategy-deployment verification, thereby realizing an intelligent and automated prevention and control pipeline for cloud-native privilege escalation vulnerabilities.

\textbf{(3) Experimental evaluation:} Privilege escalation vulnerability samples from the past five years serve as experimental subjects, and the quality and efficiency of security strategies generated by KPEDefense are evaluated along with case analyses. Experimental results show that, compared to existing rule-based risk scanning methods, KPEDefense provides more practical mitigation solutions for real-world cloud-native privilege escalation vulnerabilities; each component of the method makes a positive contribution to strategy effectiveness; and the time and economic cost overhead is low.

By generating intelligent vulnerability prevention and control security strategies, KPEDefense can effectively mitigate high-risk threats such as privilege escalation posed by third-party open-source applications in Kubernetes, thereby ensuring the security of Kubernetes clusters.

\EnglishKeywords{Cloud-native security; Privilege escalation vulnerabilities; Strategy code generation; Patch-window mitigation; Multi-agent collaboration}
\end{EnglishAbstract}
