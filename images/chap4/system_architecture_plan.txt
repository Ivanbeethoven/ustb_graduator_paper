========================================================
KPEAgent 系统架构图绘制规划
UML 组件图 (Component Diagram) — gen_architecture_v2.py
========================================================

一、画布参数
  - 尺寸: 17" × 11"，DPI=200（输出 3400×2200 px）
  - 坐标系: matplotlib 默认（左下角原点，x 右、y 上）
  - 背景色: white
  - set_aspect('equal') 保证比例一致

二、字体
  - 中文: ['SimHei', 'Microsoft YaHei', 'Arial']
  - axes.unicode_minus = False

三、图层色彩方案（UML 分层标注）
  L1 展现层:   fill=#E3F2FD, border=#1565C0 (蓝)
  L2 服务层:   fill=#FFF3E0, border=#E65100 (橙)
  L3 智能引擎层: fill=#F3E5F5, border=#6A1B9A (紫)
  L4 数据层:   fill=#E8F5E9, border=#2E7D32 (绿)
  组件默认:    fill=white,   border=#546E7A (深蓝灰)
  外部系统:    fill=#ECEFF1, border=#78909C, 线型=虚线

四、层带（Layer Band）定位
  ┌ 图例：x 范围均为 [0.3, 14.4]，层间留 0.25 间隙 ┐
  L1 展现层:    y 范围 = [8.7,  10.6]   高 1.9
  L2 服务层:    y 范围 = [5.2,   8.45]  高 3.25
  L3 智能引擎层: y 范围 = [2.65,  4.95]  高 2.3
  L4 数据层:    y 范围 = [0.4,   2.4]   高 2.0
  层带圆角矩形: boxstyle='round,pad=0.12', lw=2.0
  层带左上角标注: 格式 "«layer» 层名 (英文名)"，fontsize=10, bold

  L2 内子框（核心业务逻辑）:
    x=[0.55, 14.1], y=[5.42, 7.05]
    fill=#FFF8E1, border=#F57C00, linestyle='--', lw=1.0
    左上角标注: "核心业务逻辑", fontsize=8.5, color=#E65100

五、组件（Component）绘制规范
  每个组件 = 实线矩形框 + 内部两行文字 + 右上角 UML 组件图标
  矩形: FancyBboxPatch, boxstyle='square,pad=0', fill=white, border=#546E7A, lw=1.2
  第一行（构造型）: «component», fontsize=7, italic, color=#666, 居中
  第二行（名称）:  组件名, fontsize=9, bold, 居中
  第三行（可选）:  技术标注 (如 Flask / SDK), fontsize=7.5, color=#444, 居中
  右上角图标: UML component icon（小矩形+两个 tab 突起），见函数 draw_comp_icon()
    图标总宽约 0.20，高约 0.22，位于组件右上角内侧

  默认尺寸: w=3.0, h=0.88（各层适当缩放）

六、各层组件定位（cx=中心x, cy=中心y）
  ─── L1 展现层 (cy=9.65) ───
  A: Vue3 视图组件        cx=2.5,  w=3.0, h=0.88

  ─── L2 服务层 ───
  D: REST API 网关 (Flask)  cx=3.6,  cy=7.75, w=3.5,  h=0.88
  E: 任务调度器              cx=9.8,  cy=7.75, w=3.0,  h=0.88

  G: 策略生成                cx=5.0,  cy=6.2,  w=2.5,  h=0.85

  A2: REST API(右) → 调度器(左)       [内部 dispatch]

       标签: "K8s API / SSH"

八、辅助函数清单
  draw_layer_band(ax, x0, y0, w, h, label_cn, label_en, lcolor, fcolor)
  draw_comp_icon(ax, x_right, y_top, color)   — UML 组件图标（右上角小符号）
  draw_component(ax, cx, cy, w, h, name, sub='', border=..., fill=...)
  draw_datastore(ax, cx, cy, w, h, name, sub='', fcolor=..., bcolor=...)
  draw_external(ax, cx, cy, w, h, name, sub='')
  draw_line_arrow(ax, pts, label='', ls='-', color='#37474F', lx=None, ly=None)
  draw_curve_arrow(ax, x1,y1,x2,y2, label='', rad=-0.3, lx=None, ly=None)

九、输出
